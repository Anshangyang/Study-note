## 1. 命令

Linux命令有很多，在这里只列举常用的几个，而类似于vim此类工具的命令将会着重讲述。

### man

- 用法：man 命令
- 可查看其他命令的说明文档。

### ls

- 用法：ls/ls -a/ls -l
- 可查看当前目录下所有文件，-a参数可查看隐藏文件，-l参数可查看文件权限。

### adduser

- 用法：adduser 用户名/adduser 用户名 sudo
- 创建新用户，将用户加入sudo组。

### su

- 用法：su/su 用户名
- 切换用户，单独使用时切换到root。

### touch

- 用法：touch 文件名
- 创建文件。

### mkdir

- 用法：mkdir 目录名
- 创建目录。

### rmdir

- 用法：rmdir 目录名
- 删除空目录。

### rm

- 用法：rm 文件名/rm -r 目录名
- 删除文件，-r参数删除目录。

### cp

- 用法：cp 源文件 新文件
- 复制文件。

### mv

- 用法：mv 源文件 路径
- 移动文件。

### echo

- 用法：echo 文本
- 在终端输出文本。

### >

- 用法：echo 文本 > 文件
- 覆写文件。

### >>

- 用法：echo 文本 >> 文件
- 在文件里附加文本。

### cat

- 用法：cat 文件名
- 查看文件内容。

### chmod

- 用法：chmod 文件名 777
- 修改文件权限。

### grep

- 用法：grep 文本 文件名
- 在文件里进行搜索。

### |

- 用法：grep 文本 文件名 | cut -d " " -f 2
- 将上一个命令或工具执行后的结果转移到下一个命令或工具继续执行。

### cut

- 用法：cut -d " " -f 2
- 以行为单位。-d参数指定分隔符，-f指定其位数进行筛选。

### sed

- 用法：sed 's/要查找的内容/替换成的内容/标志' 文件名
- 替换文件里你想替换的文本或内容。

### awk

- 用法：awk '$1 > 5' 文件名
- 使用$符号选择指定字段，创建检索规则。

### service
- 用法：service 服务名 start/stop/restart
- 用来启动、停止、重启服务。

### ifconfig
- 用法：ifconfig
- 查看网络信息。

### netstat
- netstat
- 查看网络连接和开放端口。

## 2. 补充

1.可以使用root权限的用户需加入sudoers文件中。

2.文件访问权限分为读(r)、写(w)、执行(x)，使用chmod修改权限，访问对象也分为创建人(owner)、所属用户组(group)、其他人，注意顺序。

3.设置静态ip地址需修改配置文件，即/etc/network/interfaces，添加网络接口eth0，添加IP地址、子网掩码、网关即可。
