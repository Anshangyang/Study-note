## 1. 认识C语言

```c
hello.c

#include <stdio.h>
int main(void){

    printf("Hello World!\n");

    return 0;

}
```

### 1.1 C程序的结构

#### 1.1.1 整体结构

##### 程序与标准库

- C程序的整体结构很清晰，或者说编程语言的整体结构都很清晰，重要的是理解各语言之间基本结构的差异。
- 在这里讲解的整体结构不是单个程序里的块级结构，而是多个程序文件之间如何协同工作，整体的认识C程序。
- **标准库**：*C语言自带的官方库，不需要下载，只需要使用 `#include` 引入对应的头文件就可以直接使用。*
> 补充：除 **标准库** 以外，还有 **第三方库** 、 **自定义库** 。
- **头文件**：相当于你想使用的那个工具所处的工具箱，例如 `<stdio.h>` ，而 `#include` 则是你与存放工具箱的 **标准库** 之间的仓库管理员。
> 提示：以上便是一个程序与 **标准库** 的大致关系。

##### 多文件程序与函数调用

- 多个程序文件之间如果需要引用对方的 **函数** ，需要在程序开始前进行 **声明** ，或者引用头文件。
- **函数**：*具有特定功能或作用的独立代码块，也是一个C程序的核心。*
- **变量**：*程序中可以变化的数值，是存储数据的容器。*
- **数据类型**：*通常使用在 **变量** 上，决定变量值的类型，并为变量值分配内存存储空间。*
- **声明**：*在一个程序里宣布一个 **变量** 的存在，一并确定此 **变量** 的 **数据类型**。*
> 提示：如果需要引用的函数过多，引用头文件会更方便，头文件的编写也很简单：
> 1.创建一个.h文件。
> 2.将你需要使用的 **函数声明** （**函数原型**）写进去。
> 3.在程序中用 `#include` 引入即可。
> 
> 补充：**函数声明** 和 **函数原型** 将会在讲解函数时进行解释。

#### 1.1.2 单个C程序的块级结构

##### 单个C程序的基础概念与结构


- C程序的开始，有人认为是从 `#include <stdio.h>` 开始的，有人认为是从 **函数** `main()` 开始的，实际上，不管以上两种观点正确与否， **函数**  `main()` 都是C程序运行时的开始，所以，笔者更认可第二种观点。
> 提示：不必纠结这个问题，因为这个问题的答案不同是因为每个人观察它的方式不同，你真正需要记住的是***函数 `main()` 是C程序运行时的开始。***
- 根据我们对于本章节 `hello.c` 文件的观察，我们可以发现， **函数** `main()` 的前面和括号内有着 `int` 和 `void` 的字样，这两个是什么？分别有什么作用？这就是我们接下来讲解的内容。
- **函数头**：`int main(void)` 这一行代码的名字，顾名思义，即为 **函数** 的头部。`int` 是一个 **数据类型** ，用在前面，代表着这个函数需要这种 **数据类型** 的信息来完成它的功能或作用；`void` 被包括在 `main()` 的括号里，这个括号一般来说是用来给这个 **函数** 传递它需要的信息的，类似于 `int x` ，但是在这里的是 `void` ，这意味着它是一个 **空函数** ，它不返回任何值。
- **空函数**：一个 **函数** 被编写出来大多是为了完成某种特定功能或作用，假设某个 **函数** ，我们用它来进行两个四位数的加减乘除，我们将想要进行加减乘除的两个数传递给它，它就要给我们返回它求出的值，这个值就叫做 **返回值** 。可也有一些函数我们不需要它返回任何值，那这个 **函数** 就叫做 **空函数**。
> 提示：返回值已做解释，如不理解，可以当作 *函数这个独立代码块运行的结果。*
- 现在，我们来看 **函数头** 下方用大括号括起来的部分，这部分叫做 **函数体** 它就是 **函数** 的独立代码块，现在，先让我们来解析一下 `printf("Hello World!");` 以及 `return 0;` 、 `\n`。

```c
hello.c

int main(void){

    printf("Hello World!\n");

    return 0;

}
```

- **输入/输出函数**：这是 **标准库** `<stdio.h>` 里包含的一个非常非常通用的函数，用来把程序执行后产生的结果打印到终端，也就是显示在屏幕上。
- return语句：有 **返回值** 的 **函数** 都应在结尾有return语句，语句以return **关键字** 开始，后面是要返回的值。
> 提示：**函数main()** 里的return语句可以省略，但不推荐，养成习惯，以防在有 **返回值** 的函数里省略。
- **转义序列**：形如 `\n` ，代表难以表示或无法输入的字符，例如换行、制表符、退格键等。
> 提示：`\n` 代表换行。
